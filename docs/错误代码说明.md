# 错误代码说明

当引擎遇到不可忽略的错误时，会弹出仿 Windows 蓝屏的错误界面（蓝底白字），
显示报错模块、16 进制错误代码与原因分析。本文档列出所有错误代码及其含义，
供玩家与开发者对照排查。

错误代码采用 16 进制显示（带 `0x` 前缀，8 位补零），按模块分段：

| 段位 | 模块 | 说明 |
|------|------|------|
| `0xC001_xxxx` | 剧本 | 剧本编译、运行时、资源引用相关错误 |
| `0xC002_xxxx` | 存档 | 存档读写相关错误 |
| `0xC003_xxxx` | 渲染 | 渲染层资源加载 / 绘制相关错误 |
| `0xC004_xxxx` | 配置 | 设置文件解析、翻译加载相关错误 |
| `0xDEAD_xxxx` | 致命 | 未知致命错误（兜底） |

## 错误代码对照表

| 错误代码 | 报错模块 | 原因分析 |
|----------|----------|----------|
| `0xC0010001` | 剧本编译器 | 剧本编译失败，存在词法、语法或类型检查错误，请检查剧本文件。 |
| `0xC0010002` | 运行时 | 剧本运行时发生错误，VM 执行期间抛出异常。 |
| `0xC0010003` | 运行时 | 剧本引用的资源（背景/立绘/音乐/语音）缺失，请补齐资源文件。 |
| `0xC0020001` | 运行时 | 存档读取失败，文件可能损坏或与当前版本不兼容。 |
| `0xC0030001` | 渲染 | 渲染层出现异常，资源加载或绘制失败。 |
| `0xC0040001` | 运行时 | 设置文件解析失败，配置可能已损坏。 |
| `0xDEAD0001` | 未知 | 发生未知致命错误，建议导出日志并重启引擎。 |

## 蓝屏界面操作

蓝屏界面右下角提供三个按钮：

1. **导出日志** — 将终端最近 30 条日志（不足 30 条时按实际数量导出）写入用户选择的目录，文件名形如 `crash_log_<时间戳>.txt`。点击后会弹出应用内目录选择器，可逐级进入子目录或返回上级目录。
2. **尝试继续运行** — 对于非灾难性错误（例如剧本编译错误可降级到仅标题页），尝试继续运行引擎。若崩溃信息标记为不可继续，此按钮置灰不可点击。
3. **退出引擎** — 直接退出整个引擎进程。

> 蓝屏界面顶部会显示固定警告：**「如果遇到灾难性错误，点击继续运行也有可能退出游戏」**。
> 即使点击「尝试继续运行」，灾难性错误仍可能导致引擎在后续操作中退出。

## 日志导出格式

导出的日志文件包含：

- 标题行 `Akizuki*Rustgal 崩溃日志导出`
- 导出时的 Unix 时间戳
- 日志条数
- 编号日志列表（`01. ...`、`02. ...`，按时间顺序，旧 → 新）
- 若无日志记录，则写入 `（无日志记录）`

## 代码常量定义

错误代码常量定义于 `crates/akrs-runtime/src/crash.rs` 的 `error_code` 模块，
原因分析的 UI 翻译 key 由 `reason_code()` 函数映射，对应翻译文件位于
`assets/scripts/languages/ui/*.json`（`error.module.*` 与 `error.reason.*` 前缀）。
