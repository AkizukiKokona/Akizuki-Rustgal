# 翻譯功能使用說明

Akizuki\*Rustgal 引擎內建完整的多語言翻譯系統，採用「原文即 key」策略，**原劇本完全不需要修改**，只需新增翻譯檔案即可支援任意語言。

---

## 設計原則

- **原文即 key** — 翻譯檔案以原文文字為鍵，譯文為值，原劇本一行不改。
- **注入點在 Engine 層** — VM 和編譯器零改動，切換語言無需重新編譯、不影響存檔。
- **顯示層翻譯，邏輯層不變** — 角色名、章節名等在邏輯層（跳轉、舞台管理、存檔元資料）始終用原文，僅在顯示給玩家前查表替換。
- **回退原文** — 找不到譯文或譯文為空時直接回傳原文，遊戲不會因缺少翻譯而報錯。
- **零熱路徑分配** — 查詢是 `HashMap::get` 均攤 O(1)，不分配記憶體。

---

## 翻譯檔案格式

翻譯檔案為 JSON 格式，存放在 `assets/scripts/languages/` 目錄下，檔名為語言代碼（如 `ja-JP.json`）。

```json
{
  "language": "ja-JP",
  "display_name": "日本語",
  "sections": {
    "夏日祭的尾声": "夏祭りの終わりに"
  },
  "dialogue": {
    "引航者，今天晚上玩得开心吗？": "ナビゲーター、今夜は楽しかった？"
  },
  "narration": {
    "心夏低下了头。": "心夏は頭を下げた。"
  },
  "choices": {
    "我有个小礼物想送给心夏": "心夏にちょっとしたプレゼントがある"
  },
  "choice_prompts": {
    "引航者要对心夏说什么？": "ナビゲーターは心夏に何を言う？"
  },
  "characters": {
    "心夏": "心夏",
    "引航者": "ナビゲーター"
  }
}
```

### 欄位說明

| 欄位 | 類型 | 說明 |
|------|------|------|
| `language` | string | 語言代碼，如 `zh-CN`、`en-US`、`ja-JP` |
| `display_name` | string | 語言顯示名，如 `簡體中文`、`English`、`日本語` |
| `sections` | object | 章節標題翻譯（`#` 開頭的行） |
| `dialogue` | object | 對話文字翻譯（`角色名: "文字"` 格式的行） |
| `narration` | object | 旁白文字翻譯（獨立引號行） |
| `choices` | object | 分支選項文字翻譯（`|` 開頭的行） |
| `choice_prompts` | object | 選項提示語翻譯（`?` 開頭的行） |
| `characters` | object | 角色名翻譯（僅顯示層替換，邏輯層用原文） |

> **空譯文**：value 為空字串 `""` 表示「未翻譯」，執行時會回退顯示原文。

---

## 可翻譯內容

翻譯系統涵蓋以下六類劇本元素：

| 類別 | 劇本語法 | 範例 |
|------|----------|------|
| 章節標題 | `# 標題` | `# 夏日祭的尾聲` |
| 對話 | `角色名: "文字"` | `心夏: "今天開心嗎？"` |
| 旁白 | `"文字"` | `"心夏低下了頭。"` |
| 選項提示 | `? "提示"` | `? "你要說什麼？"` |
| 選項 | `\| "文字" -> 跳轉` | `\| "送禮物" -> 分支A` |
| 角色名 | 對話行中冒號前的部分 | `心夏` |

## 產生翻譯骨架（CLI）

使用命令列工具自動掃描劇本，產生包含所有可翻譯文字的 JSON 骨架檔案：

```bash
# 基本用法
akrs translate init <剧本文件> <语言代码>

# 示例：为 demo.akrs 生成日语翻译骨架
akrs translate init scripts/demo.akrs ja-JP > assets/scripts/languages/ja-JP.json

# 生成英语翻译骨架
akrs translate init scripts/demo.akrs en-US > assets/scripts/languages/en-US.json
```

### 支援的語言代碼

| 代碼 | 顯示名 |
|------|--------|
| `zh-CN` | 簡體中文 |
| `zh-TW` | 繁體中文 |
| `en-US` | English |
| `ja-JP` | 日本語 |

其他語言代碼也可使用，`display_name` 會預設設為語言代碼本身，可在產生的 JSON 中手動修改。

### 輸出範例

```
✓ Generated translation skeleton for 'ja-JP'
  Sections: 4
  Dialogue: 40
  Narration: 5
  Choices: 2
  Choice prompts: 1
  Characters: 2
```

產生的 JSON 中所有譯文為空字串 `""`，翻譯者只需填入對應譯文即可。

## 編輯器對照翻譯模式

編輯器內建對照翻譯功能，提供原文-譯文並排視圖，便於翻譯者逐行翻譯。

### 開啟方式

點擊編輯器工具列的 **「對照翻譯」** 按鈕切換翻譯模式。

### 界面說明

```
┌─────────────────────────────────────────────┐
│ 目标语言：[ja-JP]  [加载] [重新提取] [保存]  │
│ 共 52 行可翻译                                │
├─────────────────────────────────────────────┤
│ [对话]  行 92   #1                           │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 引航者，今天晚上玩得开心吗？               │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ ナビゲーター、今夜は楽しかった？           │ │
│ └────────────────────────────────────────┘ │
│                                             │
│ [旁白]  行 97   #2                          │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 心夏低下了头。                           │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ 心夏は頭を下げた。                       │ │
│ └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 操作步驟

1. **輸入目標語言代碼**（如 `ja-JP`）
2. **點擊「載入」** — 從 `assets/scripts/languages/<語言>.json` 載入已有翻譯（若檔案不存在則新建空翻譯表）
3. **逐行翻譯** — 在「譯文」輸入框中填入譯文，修改會即時寫入翻譯表
4. **點擊「儲存翻譯」** — 將翻譯表序列化為 JSON 儲存到 `assets/scripts/languages/<語言>.json`

### 輔助功能

- **類型標籤** — 每行前標註類型（`对话`/`旁白`/`章节`/`选项`/`提示`/`角色`），不同類型用不同顏色區分
- **行號顯示** — 顯示原文在劇本中的行號，便於定位
- **重新提取** — 劇本修改後點擊「重新提取」重新整理可翻譯文字列表
- **原文唯讀** — 原文區域不可編輯，確保翻譯基於正確的原文

## 執行時語言切換

### 設定頁切換

在遊戲內設定頁面可透過 **語言下拉式選單** 即時切換語言：

1. 打開設定頁面
2. 找到「語言」選項
3. 從下拉式選單中選擇目標語言
4. 遊戲立即套用翻譯，無需重新啟動

### 翻譯檔案載入

遊戲啟動時按以下順序載入翻譯：

1. 讀取 `ProjectConfig` 中的 `language` 欄位（專案預設語言）
2. 若為空，偵測系統語言（`LANG`/`LC_ALL` 等環境變數）
3. 從 `assets/scripts/languages/<語言代碼>.json` 載入翻譯檔案
4. 若檔案不存在，使用原文模式（所有文字顯示原文）

### 專案設定

在編輯器「專案設定」對話方塊的「執行設定」區域可設定：

| 欄位 | 說明 |
|------|------|
| 預設語言 | 專案啟動時使用的語言代碼（如 `ja-JP`），留空則偵測系統語言 |
| 視窗標題 | 遊戲視窗標題，留空則使用主標題 |
| 版本號 | 專案版本號（如 `v1.0.0`） |
| 預設解析度 | 啟動解析度（預設 1920×1080） |
| 啟動時全螢幕 | 是否以全螢幕模式啟動 |

## 翻譯檔案目錄結構

```
assets/
└── scripts/
    ├── demo.akrs                  原文剧本（不修改）
    └── languages/
        ├── zh-CN.json             简体中文翻译
        ├── zh-TW.json             繁体中文翻译
        ├── en-US.json             英语翻译
        └── ja-JP.json             日语翻译
```

> 每個翻譯檔案與原文劇本一一對應，新增語言只需在 `languages/` 目錄下新增對應 JSON 檔案。

---

## 注意事項

1. **原文不可修改** — 翻譯檔案以原文為 key，修改原文會導致翻譯失效。如需修改原文，請重新執行 `translate init` 產生骨架並重新翻譯。
2. **角色名僅替換顯示** — 邏輯層（角色上場/下場/存檔/跳轉）始終使用原文角色名，翻譯僅在螢幕顯示時生效。
3. **空譯文回退原文** — 譯文為空字串時自動回退顯示原文，不會報錯。
4. **熱重載相容** — 修改翻譯檔案後可透過熱重載即時生效，無需重新啟動遊戲。
5. **存檔相容** — 存檔中儲存的是原文文字和章節名，切換語言不影響存檔載入。
