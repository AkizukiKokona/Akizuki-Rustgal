# 翻訳機能使用説明

Akizuki\*Rustgal エンジンには完全な多言語翻訳システムが内蔵されており、「原文即 key」戦略を採用しています。**原スクリプトは一切修正する必要がなく**、翻訳ファイルを追加するだけで任意の言語に対応できます。

---

## 設計原則

- **原文即 key** — 翻訳ファイルは原文テキストをキーとし、訳文を値とします。原スクリプトは一行も変更しません。
- **注入点は Engine 層** — VM とコンパイラは一切変更せず、言語切替時に再コンパイル不要、セーブデータにも影響しません。
- **表示層翻訳、論理層不変** — キャラクター名、セクションタイトルなどは論理層（ジャンプ、ステージ管理、セーブデータメタデータ）では常に原文を使用し、プレイヤーに表示する直前にのみテーブル参照で置換します。
- **原文へフォールバック** — 訳文が見つからない、または訳文が空の場合は原文をそのまま返します。翻訳欠落によるエラーは発生しません。
- **ホットパス割り当てゼロ** — クエリは `HashMap::get` で償却 O(1)、メモリ割り当てなし。

---

## 翻訳ファイル形式

翻訳ファイルは JSON 形式で、`assets/scripts/languages/` ディレクトリに配置され、ファイル名は言語コードです（例: `ja-JP.json`）。

```json
{
  "language": "ja-JP",
  "display_name": "日本語",
  "sections": {
    "夏日祭的尾声": "夏祭りの終わりに"
  },
  "dialogue": {
    "引航者，今天晚上玩得开心吗？": "ナビゲーター、今夜は楽しかった？"
  },
  "narration": {
    "心夏低下了头。": "心夏は頭を下げた。"
  },
  "choices": {
    "我有个小礼物想送给心夏": "心夏にちょっとしたプレゼントがある"
  },
  "choice_prompts": {
    "引航者要对心夏说什么？": "ナビゲーターは心夏に何を言う？"
  },
  "characters": {
    "心夏": "心夏",
    "引航者": "ナビゲーター"
  }
}
```

### フィールド説明

| フィールド | 型 | 説明 |
|------|------|------|
| `language` | string | 言語コード（例: `zh-CN`、`en-US`、`ja-JP`） |
| `display_name` | string | 言語表示名（例: `简体中文`、`English`、`日本語`） |
| `sections` | object | セクションタイトルの翻訳（`#` で始まる行） |
| `dialogue` | object | 対話テキストの翻訳（`キャラクター名: "テキスト"` 形式の行） |
| `narration` | object | ナレーションテキストの翻訳（独立した引用符行） |
| `choices` | object | 分岐選択肢テキストの翻訳（`|` で始まる行） |
| `choice_prompts` | object | 選択肢プロンプトの翻訳（`?` で始まる行） |
| `characters` | object | キャラクター名の翻訳（表示層のみ置換、論理層は原文を使用） |

> **空の訳文**: value が空文字列 `""` の場合は「未翻訳」を意味し、実行時に原文へフォールバックして表示します。

---

## 翻訳可能な内容

翻訳システムは以下の 6 種類のスクリプト要素をカバーします：

| カテゴリ | スクリプト構文 | 例 |
|------|----------|------|
| セクションタイトル | `# タイトル` | `# 夏日祭的尾声` |
| 対話 | `キャラクター名: "テキスト"` | `心夏: "今天开心吗？"` |
| ナレーション | `"テキスト"` | `"心夏低下了头。"` |
| 選択肢プロンプト | `? "プロンプト"` | `? "你要说什么？"` |
| 選択肢 | `\| "テキスト" -> ジャンプ` | `\| "送礼物" -> 分支A` |
| キャラクター名 | 対話行のコロン前の部分 | `心夏` |

## 翻訳スケルトンの生成（CLI）

コマンドラインツールを使用してスクリプトを自動スキャンし、すべての翻訳可能テキストを含む JSON スケルトンファイルを生成します：

```bash
# 基本的な使い方
akrs translate init <剧本文件> <语言代码>

# 例: demo.akrs の日本語翻訳スケルトンを生成
akrs translate init scripts/demo.akrs ja-JP > assets/scripts/languages/ja-JP.json

# 英語翻訳スケルトンを生成
akrs translate init scripts/demo.akrs en-US > assets/scripts/languages/en-US.json
```

### サポートする言語コード

| コード | 表示名 |
|------|--------|
| `zh-CN` | 简体中文 |
| `zh-TW` | 繁體中文 |
| `en-US` | English |
| `ja-JP` | 日本語 |

その他の言語コードも使用可能です。`display_name` はデフォルトで言語コード自体に設定され、生成された JSON 内で手動で変更できます。

### 出力例

```
✓ Generated translation skeleton for 'ja-JP'
  Sections: 4
  Dialogue: 40
  Narration: 5
  Choices: 2
  Choice prompts: 1
  Characters: 2
```

生成された JSON のすべての訳文は空文字列 `""` となっており、翻訳者は対応する訳文を入力するだけで済みます。

## エディタの対照翻訳モード

エディタには対照翻訳機能が内蔵されており、原文-訳文の並列ビューを提供して、翻訳者が行ごとに翻訳しやすくしています。

### 有効化方法

エディタツールバーの **「対照翻訳」** ボタンをクリックして翻訳モードに切り替えます。

### インターフェース説明

```
┌─────────────────────────────────────────────┐
│ 目標言語：[ja-JP]  [加载] [重新提取] [保存]  │
│ 共 52 行可翻译                                │
├─────────────────────────────────────────────┤
│ [对话]  行 92   #1                           │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 引航者，今天晚上玩得开心吗？               │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ ナビゲーター、今夜は楽しかった？           │ │
│ └────────────────────────────────────────┘ │
│                                             │
│ [旁白]  行 97   #2                          │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 心夏低下了头。                           │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ 心夏は頭を下げた。                       │ │
│ └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 操作手順

1. **目標言語コードを入力**（例: `ja-JP`）
2. **「ロード」をクリック** — `assets/scripts/languages/<言語>.json` から既存の翻訳を読み込みます（ファイルが存在しない場合は空の翻訳テーブルを新規作成）
3. **行ごとに翻訳** — 「訳文」入力ボックスに訳文を入力すると、変更はリアルタイムに翻訳テーブルに書き込まれます
4. **「翻訳を保存」をクリック** — 翻訳テーブルを JSON としてシリアライズし、`assets/scripts/languages/<言語>.json` に保存します

### 補助機能

- **タイプラベル** — 各行の前にタイプ（`対話`/`ナレーション`/`セクション`/`選択肢`/`プロンプト`/`キャラクター`）を表示し、タイプごとに異なる色で区別します
- **行番号表示** — 原文のスクリプト内行番号を表示し、位置特定を容易にします
- **再抽出** — スクリプト修正後に「再抽出」をクリックして翻訳可能テキストリストを更新します
- **原文読み取り専用** — 原文領域は編集不可で、正しい原文に基づく翻訳を保証します

## 実行時の言語切替

### 設定ページでの切替

ゲーム内の設定ページで **言語ドロップダウン** により言語をリアルタイムに切り替えられます：

1. 設定ページを開く
2. 「言語」オプションを見つける
3. ドロップダウンから目標言語を選択
4. ゲームは即座に翻訳を適用し、再起動不要

### 翻訳ファイルの読み込み

ゲーム起動時に以下の順序で翻訳を読み込みます：

1. `ProjectConfig` の `language` フィールドを読み取る（プロジェクトのデフォルト言語）
2. 空の場合、システム言語を検出（`LANG`/`LC_ALL` などの環境変数）
3. `assets/scripts/languages/<言語コード>.json` から翻訳ファイルを読み込む
4. ファイルが存在しない場合、原文モードを使用（すべてのテキストは原文を表示）

### プロジェクト設定

エディタの「プロジェクト設定」ダイアログの「実行設定」エリアで以下を設定できます：

| フィールド | 説明 |
|------|------|
| デフォルト言語 | プロジェクト起動時に使用する言語コード（例: `ja-JP`）。空の場合はシステム言語を検出 |
| ウィンドウタイトル | ゲームウィンドウのタイトル。空の場合はメインタイトルを使用 |
| バージョン番号 | プロジェクトのバージョン番号（例: `v1.0.0`） |
| デフォルト解像度 | 起動時の解像度（デフォルト 1920×1080） |
| 起動時フルスクリーン | フルスクリーンモードで起動するかどうか |

## 翻訳ファイルのディレクトリ構造

```
assets/
└── scripts/
    ├── demo.akrs                  原文剧本（不修改）
    └── languages/
        ├── zh-CN.json             简体中文翻译
        ├── zh-TW.json             繁体中文翻译
        ├── en-US.json             英语翻译
        └── ja-JP.json             日语翻译
```

> 各翻訳ファイルは原文スクリプトと 1 対 1 で対応し、新しい言語の追加は `languages/` ディレクトリに対応する JSON ファイルを追加するだけで行えます。

---

## 注意事項

1. **原文は変更不可** — 翻訳ファイルは原文を key としています。原文を変更すると翻訳が無効になります。原文を変更する必要がある場合は、`translate init` を再実行してスケルトンを生成し、再翻訳してください。
2. **キャラクター名は表示のみ置換** — 論理層（キャラクターの登場/退場/セーブ/ジャンプ）は常に原文のキャラクター名を使用し、翻訳は画面表示時にのみ有効になります。
3. **空の訳文は原文へフォールバック** — 訳文が空文字列の場合は自動的に原文へフォールバックして表示し、エラーは発生しません。
4. **ホットリロード互換** — 翻訳ファイル修正後にホットリロードで即時反映でき、ゲームの再起動は不要です。
5. **セーブデータ互換** — セーブデータに保存されるのは原文テキストとセクションタイトルであり、言語切替はセーブデータの読み込みに影響しません。
