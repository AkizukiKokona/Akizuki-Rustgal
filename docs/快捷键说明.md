# 快捷键说明

本文档汇总 Akizuki\*Rustgal 游戏（`akrs-game`）与可视化编辑器（`akrs-editor`）的全部键盘 / 鼠标快捷键。

---

## 一、游戏内操作

游戏的输入处理非常克制：键盘只有 **Esc / Space / Enter / Backspace** 四个按键，其余功能（快进、自动、快存、快读等）通过屏幕底部的 HUD 按钮用鼠标点击触发。

### 1.1 键盘按键

| 按键 | 功能 |
|------|------|
| **Space** | 推进对话（与鼠标点击对话区域等价） |
| **Enter** | 推进对话；在备注编辑弹窗中确认保存 |
| **Esc** | 上下文相关：① 游戏中 → 打开设置菜单；② 设置菜单 → 若有未应用更改则弹确认框，否则返回；③ 确认对话框 → 取消并返回前一模式；④ 备注编辑弹窗 → 丢弃缓冲区返回存档页 |
| **Backspace** | 备注编辑弹窗中删除最后一个字符 |

> 备注编辑弹窗还支持直接输入任意可打印字符（上限 60 字符）。

### 1.2 鼠标左键（HUD 按钮）

游戏中所有交互均通过鼠标左键点击触发。屏幕底部 HUD 提供以下快捷按钮：

| HUD 按钮 | 功能 |
|---------|------|
| 快进 | 切换快进模式（仅文本 / 包含语音，可在设置中配置） |
| 自动 | 切换自动播放模式 |
| 快存 | 写入独立快速存档槽位（不占用手动存档编号） |
| 快读 | 读取快速存档（仅当存在快速存档时可用） |
| 存档 | 打开存档菜单 |
| 读档 | 打开读档菜单 |
| 标题 | 返回标题界面（会弹出确认框） |
| 设置 | 打开设置菜单 |
| 隐藏 | 隐藏 / 显示 HUD（隐藏期间对话推进键被禁用，防止跳过看不见的对话） |

> 鼠标左键点击对话区域可推进对话、选择分支选项、与所有菜单界面交互。

### 1.3 平台差异

无。游戏使用 macroquad 的物理按键码（`KeyCode`），`Esc / Space / Enter / Backspace` 在 Windows / macOS / Linux 上行为完全一致，且不使用任何 Ctrl/Cmd 组合键。

## 二、编辑器操作

编辑器基于 iced 0.13，快捷键通过 `iced::keyboard` 的 `Modifiers::control()` 判断修饰键，所有快捷键均为 **Ctrl + 字母** 组合（不能同时按 Shift），另有 F5 单键和蓝图模式下的鼠标/Delete 操作。

### 2.1 文件与编辑操作

| 按键组合 | 功能 |
|---------|------|
| **Ctrl + N** | 新建剧本 |
| **Ctrl + O** | 打开文件（若欢迎页开启则关闭欢迎页并提示从左侧选择） |
| **Ctrl + S** | 保存当前文件 |
| **Ctrl + F** | 打开 / 关闭查找替换面板 |
| **Ctrl + R** | 启动游戏预览窗口（`cargo run --release -p akrs-game`） |
| **Ctrl + H** | 显示 / 隐藏快捷键帮助窗口 |
| **Ctrl + J** | 从光标所在行解析语句并跳转到对应预览标签页（等价于 Ctrl+点击） |
| **F5** | 运行当前剧本（启动游戏预览窗口，与 Ctrl+R 功能相同） |

### 2.2 Ctrl + 点击跳转预览

在剧本编辑器中按住 **Ctrl** 并点击 `@bg 背景` / `@music 音乐` / `+ 角色` 等行，右侧预览面板自动跳转到对应标签页并选中该资源，无需手动切换标签页翻找。等价于按 Ctrl+J。

> iced 的 text_editor 不暴露带修饰键的点击事件，编辑器通过全局事件过滤器（`iced::subscription`）追踪 Ctrl 按下/释放状态，再在 text_editor 的 `on_action` 回调中检测 `Move` 动作配合 Ctrl 状态实现该功能。

### 2.3 语法插入

语法插入通过工具栏的「插入语法」下拉菜单操作（非键盘快捷键），提供 `+ 角色` / `- 角色` / `# 章节` / `@bg 背景` / `@music` / `ending` / `unlock` 等常用语法模板的快速插入。在蓝图模式下该菜单自动变为「插入节点」。

### 2.4 蓝图模式操作

点击工具栏「蓝图模式」按钮进入可视化节点编辑画布后，以下鼠标和键盘操作生效：

| 操作 | 功能 |
|------|------|
| 左键点击节点 | 选中节点 |
| 左键拖动节点 | 移动节点位置 |
| 左键拖动：输出引脚 → 输入引脚 | 创建连线 |
| 右键拖动空白处 | 平移画布 |
| Ctrl + 滚轮 | 光标锚点缩放（0.2×–3.0×） |
| 右键点击空白处 | 弹出添加节点菜单（13 种模板） |
| 右键点击节点 | 弹出节点操作菜单（删除 / 编辑） |
| 双击节点 | 就地编辑节点文本 |
| **Delete** | 删除选中节点 |
| **Escape** | 关闭菜单 / 取消编辑 |

工具栏还提供「从脚本导入」「生成脚本」「整理布局」「放大 / 缩小 / 重置视图」按钮。进入蓝图模式时自动从当前脚本生成节点并自动布局，退出时自动导出为脚本文本。

### 2.5 平台差异（重要）

编辑器使用 iced 的 `Modifiers::control()` 判断修饰键。该方法反映的是**物理 Control 键**的状态：

- **Windows / Linux**：按 `Ctrl` 触发快捷键，符合用户预期。
- **macOS**：必须按**真正的 Control 键（⌃）**，而非 `Cmd`（⌘）。按 `Cmd + N` 等组合**不会**触发这些快捷键。这与原生 macOS 应用的习惯不同，使用 macOS 时请留意使用 Control 键。

> iced 的 text_editor 组件内置方向键导航、Home/End、PageUp/PageDown、Tab 缩进等标准文本编辑行为，无需额外绑定。撤销/重做（Ctrl+Z / Ctrl+Y）由编辑器自行管理的 undo/redo 历史栈提供（最近 100 步，连续输入 0.6 秒内合并为一步）。
