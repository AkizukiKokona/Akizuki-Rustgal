# 快捷键说明

本文档汇总 Akizuki\*Rustgal 游戏（`akrs-game`）与可视化编辑器（`akrs-editor`）的全部键盘 / 鼠标快捷键。

---

## 一、游戏内操作

游戏的输入处理非常克制：键盘只有 **Esc / Space / Enter / Backspace** 四个按键，其余功能（快进、自动、快存、快读等）通过屏幕底部的 HUD 按钮用鼠标点击触发。

### 1.1 键盘按键

| 按键 | 功能 |
|------|------|
| **Space** | 推进对话（与鼠标点击对话区域等价） |
| **Enter** | 推进对话；在备注编辑弹窗中确认保存 |
| **Esc** | 上下文相关：① 游戏中 → 打开设置菜单；② 设置菜单 → 若有未应用更改则弹确认框，否则返回；③ 确认对话框 → 取消并返回前一模式；④ 备注编辑弹窗 → 丢弃缓冲区返回存档页 |
| **Backspace** | 备注编辑弹窗中删除最后一个字符 |

> 备注编辑弹窗还支持直接输入任意可打印字符（上限 60 字符）。

### 1.2 鼠标左键（HUD 按钮）

游戏中所有交互均通过鼠标左键点击触发。屏幕底部 HUD 提供以下快捷按钮：

| HUD 按钮 | 功能 |
|---------|------|
| 快进 | 切换快进模式（仅文本 / 包含语音，可在设置中配置） |
| 自动 | 切换自动播放模式 |
| 快存 | 写入独立快速存档槽位（不占用手动存档编号） |
| 快读 | 读取快速存档（仅当存在快速存档时可用） |
| 存档 | 打开存档菜单 |
| 读档 | 打开读档菜单 |
| 标题 | 返回标题界面（会弹出确认框） |
| 设置 | 打开设置菜单 |
| 隐藏 | 隐藏 / 显示 HUD（隐藏期间对话推进键被禁用，防止跳过看不见的对话） |

> 鼠标左键点击对话区域可推进对话、选择分支选项、与所有菜单界面交互。

### 1.3 平台差异

无。游戏使用 macroquad 的物理按键码（`KeyCode`），`Esc / Space / Enter / Backspace` 在 Windows / macOS / Linux 上行为完全一致，且不使用任何 Ctrl/Cmd 组合键。

## 二、编辑器操作

编辑器基于 egui，所有快捷键均为 **Ctrl + 字母/数字** 组合，且不能同时按 Shift。

### 2.1 文件操作

| 按键组合 | 功能 |
|---------|------|
| **Ctrl + N** | 新建剧本 |
| **Ctrl + O** | 打开文件（若欢迎页开启则关闭欢迎页并提示从左侧选择） |
| **Ctrl + S** | 保存当前文件 |
| **Ctrl + R** | 运行当前剧本（启动游戏预览窗口） |
| **Ctrl + H** | 显示 / 隐藏快捷键帮助窗口 |

### 2.2 语法插入

| 按键组合 | 插入内容 | 说明 |
|---------|---------|------|
| **Ctrl + 1** | `+ 角色` | 立绘上场指令 |
| **Ctrl + 2** | `- 角色` | 立绘下场指令 |
| **Ctrl + 3** | `# 章节` | 章节标题 |
| **Ctrl + 4** | `@bg 背景` | 背景切换指令 |

### 2.3 平台差异（重要）

编辑器使用 egui 的 `Modifiers::ctrl` 字段判断修饰键。在 egui 中，`ctrl` 反映的是**物理 Ctrl 键**的状态：

- **Windows / Linux**：按 `Ctrl` 触发快捷键，符合用户预期。
- **macOS**：必须按**真正的 Control 键（⌃）**，而非 `Cmd`（⌘）。按 `Cmd + N` 等组合**不会**触发这些快捷键。这与原生 macOS 应用的习惯不同，使用 macOS 时请留意使用 Control 键。

> 编辑器没有绑定方向键导航、Tab 缩进、撤销/重做（Ctrl+Z/Y）、查找替换（Ctrl+F）等快捷键，这些功能通过 egui 文本编辑组件的默认行为提供。
