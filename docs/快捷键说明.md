# 快捷键说明

本文档汇总 Akizuki\*Rustgal 游戏（`akrs-game`）与可视化编辑器（`akrs-editor`）的全部键盘 / 鼠标快捷键。

---

## 一、游戏内操作

游戏的输入处理非常克制：键盘只有 **Esc / Space / Enter / Backspace** 四个按键，其余功能（快进、自动、快存、快读等）通过屏幕底部的 HUD 按钮用鼠标点击触发。

### 1.1 键盘按键

| 按键 | 功能 |
|------|------|
| **Space** | 推进对话（与鼠标点击对话区域等价） |
| **Enter** | 推进对话；在备注编辑弹窗中确认保存 |
| **Esc** | 上下文相关：① 游戏中 → 打开设置菜单；② 设置菜单 → 若有未应用更改则弹确认框，否则返回；③ 确认对话框 → 取消并返回前一模式；④ 备注编辑弹窗 → 丢弃缓冲区返回存档页 |
| **Backspace** | 备注编辑弹窗中删除最后一个字符 |

> 备注编辑弹窗还支持直接输入任意可打印字符（上限 60 字符）。

### 1.2 鼠标左键（HUD 按钮）

游戏中所有交互均通过鼠标左键点击触发。屏幕底部 HUD 提供以下快捷按钮：

| HUD 按钮 | 功能 |
|---------|------|
| 快进 | 切换快进模式（仅文本 / 包含语音，可在设置中配置） |
| 自动 | 切换自动播放模式 |
| 快存 | 写入独立快速存档槽位（不占用手动存档编号） |
| 快读 | 读取快速存档（仅当存在快速存档时可用） |
| 存档 | 打开存档菜单 |
| 读档 | 打开读档菜单 |
| 标题 | 返回标题界面（会弹出确认框） |
| 设置 | 打开设置菜单 |
| 隐藏 | 隐藏 / 显示 HUD（隐藏期间对话推进键被禁用，防止跳过看不见的对话） |

> 鼠标左键点击对话区域可推进对话、选择分支选项、与所有菜单界面交互。

### 1.3 平台差异

无。游戏使用 macroquad 的物理按键码（`KeyCode`），`Esc / Space / Enter / Backspace` 在 Windows / macOS / Linux 上行为完全一致，且不使用任何 Ctrl/Cmd 组合键。

## 二、编辑器操作

编辑器基于 egui，快捷键大多为 **Ctrl + 字母/数字** 组合。撤销/重做例外：**Ctrl + Z** 撤销，**Ctrl + Y** 或 **Ctrl + Shift + Z** 重做。

### 2.1 文件操作

| 按键组合 | 功能 |
|---------|------|
| **Ctrl + N** | 新建剧本 |
| **Ctrl + O** | 打开文件（若欢迎页开启则关闭欢迎页并提示从左侧选择） |
| **Ctrl + S** | 保存当前文件 |
| **Ctrl + R** | 运行当前剧本（启动游戏预览窗口） |
| **Ctrl + H** | 显示 / 隐藏快捷键帮助窗口 |
| **Ctrl + B** | 切换蓝图模式 / 文本模式（若当前在对照翻译模式则先退出翻译再进入蓝图） |
| **Ctrl + T** | 切换对照翻译模式（若当前在蓝图模式则先退出蓝图再进入翻译） |
| **Ctrl + Z** | 撤销文本编辑（连续输入会自动合并为一条历史，停止输入约 0.6 秒后提交） |
| **Ctrl + Y** / **Ctrl + Shift + Z** | 重做已撤销的编辑 |

> 新建 / 打开 / 加载示例会清空撤销历史（不跨文件撤销）。蓝图模式下的节点操作不纳入文本撤销栈。

> 工具栏按钮上不再标注快捷键后缀，改为鼠标悬停时显示 tooltip 提示对应快捷键。

### 2.2 语法插入

| 按键组合 | 插入内容 | 说明 |
|---------|---------|------|
| **Ctrl + 1** | `+ 角色` | 立绘上场指令 |
| **Ctrl + 2** | `- 角色` | 立绘下场指令 |
| **Ctrl + 3** | `# 章节` | 章节标题 |
| **Ctrl + 4** | `@bg 背景` | 背景切换指令 |

### 2.3 Ctrl + 鼠标点击

| 操作 | 功能 |
|------|------|
| **Ctrl + 点击 `+ 角色 ...` 行** | 将右侧立绘预览面板跳转到该行的参数（角色名、pose、位置 `at x,y`、大小 `size N` 均与代码一致）。支持全部 `+` 指令语法：带/不带 pose、带/不带 `at`/`size`、中文位置词（居左/居中/居右）等。 |
| **Ctrl + 点击 `@bg 背景` 行** | 将右侧背景预览面板跳转到该背景资源。 |
| **Ctrl + 点击 `@music 音乐` 行** | 将右侧音乐预览面板跳转到该音乐资源。 |

> 此功能用于快速核对效果：在剧本中 Ctrl+点击任意立绘 / 背景 / 音乐指令行，预览面板立即同步对应资源，无需手动在预览面板中逐项调整。

### 2.4 蓝图模式鼠标操作

蓝图模式（点击工具栏「蓝图模式」按钮进入）的交互方式参考 Unreal Engine 蓝图（精简版）：

| 操作 | 功能 |
|------|------|
| **左键点击节点** | 选中节点（底部出现文本编辑栏） |
| **左键拖动节点** | 移动节点位置 |
| **左键拖动输出引脚 → 输入引脚** | 从节点底部圆点拖到另一节点顶部圆点，创建连线 |
| **右键拖动空白处** | 平移画布 |
| **右键点击空白处**（不拖动） | 弹出添加节点菜单（13 种模板） |
| **从左侧积木面板拖出积木** | 按住积木卡片拖到画布释放，在释放处添加该类型节点 |
| **Delete** | 删除选中节点 |
| **Escape** | 关闭右键菜单 |

> 蓝图模式与文本模式可随时切换：进入蓝图时自动从当前脚本生成节点，退出时自动导出为脚本文本。

### 2.5 编辑器工具面板（右栏）

右栏「编辑器工具」面板包含若干标签页：剧本（实时预览运行）、立绘、背景、音乐、大纲，以及蓝图模式下的积木。

- **大纲**：按缩进展示剧本中的结构性行——`#` 章节、`?` 选项提示、`|` 选项、`=>` 访问子章节、`<=` 返回。每项以卡片形式呈现：填色边框 + 左侧色块标识类型 + 强调色标题 + 右侧灰色类型描述；按 `=>` 嵌套深度从左侧缩进，便于一眼看清层级。对话/旁白/指令/变量等非结构行不显示。
- **积木**（仅蓝图模式）：列出 13 种节点模板卡片，按住卡片拖到画布释放即在释放处添加该类型节点（拖拽不会被列表滚动吞掉，列表仍可用滚轮滚动）。

### 2.6 平台差异（重要）

编辑器使用 egui 的 `Modifiers::ctrl` 字段判断修饰键。在 egui 中，`ctrl` 反映的是**物理 Ctrl 键**的状态：

- **Windows / Linux**：按 `Ctrl` 触发快捷键，符合用户预期。
- **macOS**：必须按**真正的 Control 键（⌃）**，而非 `Cmd`（⌘）。按 `Cmd + N` 等组合**不会**触发这些快捷键。这与原生 macOS 应用的习惯不同，使用 macOS 时请留意使用 Control 键。

> 编辑器没有绑定方向键导航、Tab 缩进、撤销/重做（Ctrl+Z/Y）、查找替换（Ctrl+F）等快捷键，这些功能通过 egui 文本编辑组件的默认行为提供。
