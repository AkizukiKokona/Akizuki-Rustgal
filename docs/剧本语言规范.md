## 1. 总览

`.akrs` 是专为视觉小说设计的剧本语言，采用符号标记而非关键字风格：

- `#` 定义章节，`+`/`-` 控制立绘，`@` 执行舞台命令，`?`...`?` 包裹选择，`$` 操作变量
- 缩进仅作视觉用途，无语义
- 标识符支持完整 Unicode（中文角色名、章节名均可）
- 关键字极少：`if`、`else`、`end`、`wait`、`and`、`or`、`not`、`true`、`false`

```
# 章节名
@bg 背景名 with 过渡效果
+ 角色名 (立绘) 位置 with 过渡效果
角色名: "对话文本"
"旁白文本"
? "提示语"
| "选项1" -> 目标章节
| "选项2" -> 目标章节
?
$变量 = 表达式
if 条件 then
  ...
end
-> 目标章节
~~
```

## 2. 注释

以 `--` 开头，到行尾结束。仅支持单行注释，无块注释。

```akrs
-- 这是一行注释
@bg school with fade   -- 行尾注释也可以
```

## 3. 章节与入口

### 3.1 定义章节

用 `# 章节名` 定义。章节名是一个标识符，支持 Unicode，**不能含空格**。

```akrs
# 序章
心夏: "你好。"

# 第一章
"新的一天开始了。"
```

> **注意**：`# 分支 A` 会被解析为两个标识符导致错误。正确写法是 `# 分支A` 或 `# 分支_A`。

### 3.2 入口

**第一个章节**即为故事入口，游戏从这里开始执行。

### 3.3 章节末尾行为

- 执行到章节末尾时，若有调用栈（被 `=>` 访问），自动返回调用处
- 若无调用栈，视为故事结束

## 4. 对话与旁白

### 4.1 对话

`角色名: "文本"` —— 角色名后跟冒号和引号字符串。

```akrs
心夏: "今天天气真好。"
引航者: "不错不错。"
```

### 4.2 带表情/立绘的对话

`角色名 (pose): "文本"` —— 在角色名和冒号之间用括号指定表情或立绘变体。

```akrs
心夏 (happy): "太开心了！"
Aki (surprised): "What?!"
```

### 4.3 旁白

行首直接是引号字符串，无角色名和冒号。

```akrs
"心夏低下了头，不过不到一秒她又把头抬起来了。"
"微风吹过，樱花瓣飘落在空中。"
```

### 4.4 字符串

支持双引号 `"..."` 和单引号 `'...'`。支持转义：

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表符 |
| `\\` | 反斜杠 |
| `\"` | 双引号 |
| `\'` | 单引号 |

字符串不能跨行。

## 5. 舞台命令

语法：`@命令名 参数 [with 过渡效果]`。命令是非阻塞的，执行后立即继续。

### 5.1 命令列表

| 命令 | 别名 | 作用 | 参数 |
|------|------|------|------|
| `@bg` | `@background` | 切换背景图片 | 背景资源名 |
| `@music` | `@bgm` | 播放/切换背景音乐 | 音乐文件名 |
| `@sound` | `@sfx` | 播放音效 | 音效文件名 |
| `@stop_music` | `@stop_bgm` | 停止音乐 | 无 |

```akrs
@bg school with fade
@background sunset with fade_white
@music bgm_festival
@bgm summer_theme
@sound se_door
@sfx explosion
@stop_music
```

### 5.2 说明

- `with 过渡效果` 仅对 `@bg` 有效（默认 `fade`），音乐/音效命令会忽略过渡参数
- 未知命令不会报错，仅产生运行时警告
- 资源文件放在 `assets/bg/`、`assets/music/`、`assets/sound/` 目录下

## 6. 舞台方向（立绘上场/下场）

### 6.1 角色入场（`+`）

```
+ 角色名 [(立绘)] [enters] [位置] [at x,y] [size 倍数] [with 过渡]
```

所有参数均可省略，默认居中入场。

```akrs
-- 基本入场（默认居中）
+ 心夏

-- 指定立绘和位置
+ 心夏 (kokonabody1) 居中

-- 精确百分比位置
+ 心夏 at 0.3,0.8

-- 位置 + 大小
+ 心夏 at 0.5 size 1.2

-- 全参数
+ 心夏 (kokonabody1) at 0.3,0.8 size 1.2 with fade

-- 旧语法（向后兼容）
+ Aki enters from left with dissolve
```

### 6.2 预设位置

| 关键字 | 中文 | 简写 | 水平位置 |
|--------|------|------|----------|
| `left` | `居左` | `左` | 25% |
| `center` / `centre` | `居中` | `中` | 50% |
| `right` | `居右` | `右` | 75% |

> 两个角色同场时会自动调整为左-右布局。

### 6.3 精确百分比位置（`at`）

`at x,y` 使用屏幕百分比坐标精确定位：

```akrs
+ 心夏 at 0.3,0.8      -- x=30%, y=80%
+ 心夏 at 0.5           -- 只指定 x，y 默认 1.0
```

- **x**：水平位置。0.0 = 最左，0.5 = 居中，1.0 = 最右
- **y**：垂直位置。0.0 = 最顶，1.0 = 底部站立（默认值）
  - y = 1.0：立绘底部对齐屏幕底部（标准站姿，留有少量边距）
  - y < 1.0：立绘中心点对齐到该百分比位置

> `at` 只接受数字，不接受位置名。`at center` 会报错。

### 6.4 大小倍数（`size`）

```akrs
+ 心夏 size 1.2     -- 放大 20%
+ 心夏 size 0.8     -- 缩小 20%
```

立绘自然高度为屏幕高度的 80%，乘以倍数后为实际显示高度。倍数必须为正数。

### 6.5 组合使用

位置、大小可与立绘资源、过渡效果自由组合：

```akrs
+ 心夏 (kokonabody1) at 0.3,0.8 size 1.2 with fade
+ 心夏 at 0.5 size 0.9 with dissolve
+ 心夏 (happy) 居左 size 1.1 with slide_left
+ Aki (happy) left with fade              -- 裸位置名（无 from/to）
```

### 6.6 角色出场（`-`）

```
- 角色名 [exits] [with 过渡]
```

```akrs
- 心夏
- Aki
- Aki exits
- Aki with dissolve
```

### 6.7 舞台限制

同场最多 **2 个角色**。第 3 个角色入场会报错。重新上场已在场上的同名角色会替换而非新增。

> 更多立绘摆放细节请参考 [立绘摆放语法](立绘摆放语法.md)。

## 7. 选择分支

### 7.1 基本语法

```
? ["提示语"]
| "选项文本" [if 条件]
    选项体...
| "选项文本2"
    选项体2
?
```

`?` 同时作为开标记和闭标记。提示语可选，每个选项以 `|` 开头。

```akrs
? "你要说什么？"
| "你真棒！"
    $好感度 += 3
    -> 好结局
| "随便吧。"
    $好感度 -= 1
    -> 坏结局
?
```

### 7.2 内联跳转

选项体中可直接用 `->` 跳转：

```akrs
? "选择："
| "送礼物" -> 分支A
| "送衣服" -> 分支B
?
```

### 7.3 条件守卫

选项后可跟 `if 条件`，条件不满足时该选项不可选：

```akrs
? "选择："
| "表白" if $好感度 >= 10
    心夏: "..."
| "沉默"
    心夏: "..."
?
```

### 7.4 选项体

选项体可包含任意节点（对话、命令、变量操作、嵌套选择等），直到遇到下一个 `|` 或闭合 `?`。

## 8. 变量与表达式

### 8.1 变量操作

`$变量名 操作符 表达式`：

| 操作符 | 含义 |
|--------|------|
| `=` | 赋值（声明或覆盖） |
| `+=` | 加赋值（数值相加或字符串拼接） |
| `-=` | 减赋值 |

```akrs
$好感度 = 10
$分数 += 5
$生命 -= 2
$名字 = "心夏"
$pi = 3.14
```

> `+=`/`-=` 要求变量已用 `=` 声明过，否则编译报错。

### 8.2 数据类型

| 类型 | 示例 | 说明 |
|------|------|------|
| 整数 | `42`、`-5` | i64 |
| 浮点 | `3.14`、`0.5` | f64，小数点后必须有数字 |
| 字符串 | `"text"`、`'text'` | 支持转义 |
| 布尔 | `true`、`false` | `true` = 1，`false` = 0（整数别名） |

> `true`/`false` 在词法层被转为整数 1/0。真正的布尔值由比较和逻辑运算产生。

### 8.3 运算符

**算术**（优先级低→高：加减 → 乘除 → 一元负号）：

```
+  -  *  /
```

**比较**：

```
==  !=  <  >  <=  >=
```

**逻辑**（优先级低→高：or → and → not）：

```
and  or  not  !
```

> `!` 是 `not` 的符号别名。

### 8.4 表达式示例

```akrs
$好感度 > 5
$分数 >= 100 and $生命 > 0
not $已死亡
($a + $b) * 2
$好感度 >= 10 and not $对手在场
"Hello, " + $名字          -- 字符串拼接
```

> 变量引用必须带 `$` 前缀。`$` 后跟标识符名。

### 8.5 truthy 判定

以下值为假，其余为真：

- 整数 `0`
- 浮点 `0.0`
- 空字符串 `""`
- `null`

## 9. 流程控制

### 9.1 章节跳转（`->`）

`-> 章节名` —— 单向跳转，清空调用栈。

```akrs
-> 第一章
-> 收束
```

### 9.2 访问并返回（`=>` / `<=`）

- `=> 章节名` —— 压入调用栈后跳转，可返回
- `<=` —— 从访问返回调用处

```akrs
# Main
Aki: "Before."
=> Sub
Aki: "After."

# Sub
Aki: "In sub."
<=
```

> `<=` 可省略：被访问章节执行到末尾时会自动返回。若无调用栈可弹，`<=` 会报错。

### 9.3 条件分支（`if`/`else`/`end`）

```
if 表达式
    体
else
    否则体
end
```

`else` 可选，`end` 必填。

```akrs
if $好感度 > 5
    心夏: "太好了！"
else
    心夏: "再努力一下..."
end
```

> 条件表达式必须为布尔类型，否则编译报错。

### 9.4 等待（`wait`）

`wait 秒数` —— 暂停执行指定时间。

```akrs
wait 2.0
wait 1
```

### 9.5 故事结束（`~~`）

`~~` —— 标记故事结束，游戏进入结束画面。必须成对书写，单个 `~` 非法。

```akrs
心夏: "晚安～"
~~
```

## 10. 过渡效果

在 `@bg`、`+`、`-` 后使用 `with 过渡名` 指定过渡效果：

| 名称 | 效果 | 时长 |
|------|------|------|
| `fade` | 淡入淡出 | 0.6s |
| `fade_black` | 黑屏过渡 | 0.8s |
| `fade_white` | 白屏过渡 | 0.8s |
| `dissolve` | 溶解 | 0.8s |
| `slide_left` | 向左滑入 | 0.5s |
| `slide_right` | 向右滑入 | 0.5s |
| `slide_up` | 向上滑入 | 0.5s |
| `slide_down` | 向下滑入 | 0.5s |
| `wipe_left` | 向左擦除 | 0.5s |
| `wipe_right` | 向右擦除 | 0.5s |
| `blur` | 模糊过渡 | 0.6s |
| `instant` / `cut` | 立即切换 | 0s |

```akrs
@bg school with fade
+ 心夏 with dissolve
- Aki with slide_left
@bg sunset with instant
```

> 未知过渡名会在解析期报错，并列出所有合法名称。

## 11. 编译时检查

剧本在运行前会经过编译时检查，以下错误会在编译期被拦截：

### 11.1 报错的规则

| 规则 | 错误信息 |
|------|---------|
| 重复章节名 | `duplicate section name: 'X'` |
| 跳转目标不存在 | `undefined section: 'X'`（附带相似名建议） |
| 同场角色超过 2 个 | `too many characters on stage: 'X' would be the 3rd (limit is 2)` |
| `+=`/`-=` 操作未声明变量 | `undefined variable: 'X'` |
| 表达式引用未声明变量 | `undefined variable: 'X'` |
| 算术运算类型不兼容 | `cannot apply X to Y and Z` |
| `and`/`or` 操作数非布尔 | `expected bool, found X` |
| `if` 条件非布尔 | `if condition must be bool, found X` |
| 选择项条件非布尔 | `choice condition must be bool, found X` |
| 一元负号作用于非数值 | `cannot negate X` |
| `size` 值非正数 | `size must be positive` |

### 11.2 报警告的规则

| 规则 | 信息 |
|------|------|
| 无任何章节 | `no sections defined` |
| 资源引用未找到 | `resource 'X' not found`（仅当声明了资源目录时检查） |

### 11.3 分支独立检查

选择项体与 `if`/`else` 体各自独立模拟同场角色，互斥分支不累加。即一个选项让 A 入场、另一选项让 B 入场，不会被误判为同场 3 人。

## 12. 完整示例

```akrs
-- ========== 序章 ==========
# Start

@bg school with fade
+ 心夏 (kokonabody1) 居中 with dissolve

"夏日祭的夜晚，灯火通明。"

心夏: "引航者，今天晚上玩得开心吗？"
引航者: "不错不错，可惜今晚是最后一天了。"

心夏 (happy): "没关系呀，夏日祭结束了引航者又不会消失。"

-- 设置变量
$好感度 = 0

-- 分支选择
? "引航者要对心夏说什么？"
| "我有个小礼物想送给心夏"
    $好感度 += 3
    -> 分支A
| "我给心夏买了一套衣服"
    $好感度 += 2
    -> 分支B
?

-- ========== 分支A ==========
# 分支A

@bg cg with fade
- 心夏

心夏: "真的吗？我看看......居然是合照！"
引航者: "只是一点小心意而已。"

-> 收束

-- ========== 分支B ==========
# 分支B

- 心夏
+ 心夏 (kokonabody3) 居中

心夏: "和之前的感觉差不多，多谢引航者啦。"

-> 收束

-- ========== 收束 ==========
# 收束

"投影显示的时间变成了00:00。"

if $好感度 >= 3
    心夏: "引航者，我也有句重要的话要说。"
    心夏: "其实我对引航者有一种不一样的情感呢。"
else
    心夏: "时间不早了，该休息了。"
end

心夏: "引航者明天见，晚安～"
~~
```
