# 翻译功能使用说明

Akizuki\*Rustgal 引擎内置完整的多语言翻译系统，采用「原文即 key」策略，**原剧本完全不需要修改**，只需新增翻译文件即可支持任意语言。

---

## 设计原则

- **原文即 key** — 翻译文件以原文文本为键，译文为值，原剧本一行不改。
- **注入点在 Engine 层** — VM 和编译器零改动，切语言无需重编译、不影响存档。
- **显示层翻译，逻辑层不变** — 角色名、章节名等在逻辑层（跳转、舞台管理、存档元数据）始终用原文，仅在显示给玩家前查表替换。
- **回退原文** — 找不到译文或译文为空时直接返回原文，游戏不会因缺少翻译而报错。
- **零热路径分配** — 查询是 `HashMap::get` 均摊 O(1)，不分配内存。

---

## 翻译文件格式

翻译文件为 JSON 格式，存放在 `assets/scripts/languages/` 目录下，文件名为语言代码（如 `ja-JP.json`）。

```json
{
  "language": "ja-JP",
  "display_name": "日本語",
  "sections": {
    "夏日祭的尾声": "夏祭りの終わりに"
  },
  "dialogue": {
    "引航者，今天晚上玩得开心吗？": "ナビゲーター、今夜は楽しかった？"
  },
  "narration": {
    "心夏低下了头。": "心夏は頭を下げた。"
  },
  "choices": {
    "我有个小礼物想送给心夏": "心夏にちょっとしたプレゼントがある"
  },
  "choice_prompts": {
    "引航者要对心夏说什么？": "ナビゲーターは心夏に何を言う？"
  },
  "characters": {
    "心夏": "心夏",
    "引航者": "ナビゲーター"
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `language` | string | 语言代码，如 `zh-CN`、`en-US`、`ja-JP` |
| `display_name` | string | 语言显示名，如 `简体中文`、`English`、`日本語` |
| `sections` | object | 章节标题翻译（`#` 开头的行） |
| `dialogue` | object | 对话文本翻译（`角色名: "文本"` 格式的行） |
| `narration` | object | 旁白文本翻译（独立引号行） |
| `choices` | object | 分支选项文本翻译（`|` 开头的行） |
| `choice_prompts` | object | 选项提示语翻译（`?` 开头的行） |
| `characters` | object | 角色名翻译（仅显示层替换，逻辑层用原文） |

> **空译文**：value 为空字符串 `""` 表示「未翻译」，运行时会回退显示原文。

---

## 可翻译内容

翻译系统覆盖以下六类剧本元素：

| 类别 | 剧本语法 | 示例 |
|------|----------|------|
| 章节标题 | `# 标题` | `# 夏日祭的尾声` |
| 对话 | `角色名: "文本"` | `心夏: "今天开心吗？"` |
| 旁白 | `"文本"` | `"心夏低下了头。"` |
| 选项提示 | `? "提示"` | `? "你要说什么？"` |
| 选项 | `\| "文本" -> 跳转` | `\| "送礼物" -> 分支A` |
| 角色名 | 对话行中冒号前的部分 | `心夏` |

## 生成翻译骨架（CLI）

使用命令行工具自动扫描剧本，生成包含所有可翻译文本的 JSON 骨架文件：

```bash
# 基本用法
akrs translate init <剧本文件> <语言代码>

# 示例：为 demo.akrs 生成日语翻译骨架
akrs translate init scripts/demo.akrs ja-JP > assets/scripts/languages/ja-JP.json

# 生成英语翻译骨架
akrs translate init scripts/demo.akrs en-US > assets/scripts/languages/en-US.json
```

### 支持的语言代码

| 代码 | 显示名 |
|------|--------|
| `zh-CN` | 简体中文 |
| `zh-TW` | 繁體中文 |
| `en-US` | English |
| `ja-JP` | 日本語 |

其他语言代码也可使用，`display_name` 会默认设为语言代码本身，可在生成的 JSON 中手动修改。

### 输出示例

```
✓ Generated translation skeleton for 'ja-JP'
  Sections: 4
  Dialogue: 40
  Narration: 5
  Choices: 2
  Choice prompts: 1
  Characters: 2
```

生成的 JSON 中所有译文为空字符串 `""`，翻译者只需填入对应译文即可。

## 编辑器对照翻译模式

编辑器内置对照翻译功能，提供原文-译文并排视图，便于翻译者逐行翻译。

### 开启方式

点击编辑器工具栏的 **「对照翻译」** 按钮切换翻译模式。

### 界面说明

```
┌─────────────────────────────────────────────┐
│ 目标语言：[ja-JP]  [加载] [重新提取] [保存]  │
│ 共 52 行可翻译                                │
├─────────────────────────────────────────────┤
│ [对话]  行 92   #1                           │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 引航者，今天晚上玩得开心吗？               │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ ナビゲーター、今夜は楽しかった？           │ │
│ └────────────────────────────────────────┘ │
│                                             │
│ [旁白]  行 97   #2                          │
│ ┌─ 原文 ──────────────────────────────────┐ │
│ │ 心夏低下了头。                           │ │
│ └────────────────────────────────────────┘ │
│ ┌─ 译文 ──────────────────────────────────┐ │
│ │ 心夏は頭を下げた。                       │ │
│ └────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 操作步骤

1. **输入目标语言代码**（如 `ja-JP`）
2. **点击「加载」** — 从 `assets/scripts/languages/<语言>.json` 加载已有翻译（若文件不存在则新建空翻译表）
3. **逐行翻译** — 在「译文」输入框中填入译文，修改会实时写入翻译表
4. **点击「保存翻译」** — 将翻译表序列化为 JSON 保存到 `assets/scripts/languages/<语言>.json`

### 辅助功能

- **类型标签** — 每行前标注类型（`对话`/`旁白`/`章节`/`选项`/`提示`/`角色`），不同类型用不同颜色区分
- **行号显示** — 显示原文在剧本中的行号，便于定位
- **重新提取** — 剧本修改后点击「重新提取」刷新可翻译文本列表
- **原文只读** — 原文区域不可编辑，确保翻译基于正确的原文

## 运行时语言切换

### 设置页切换

在游戏内设置页面可通过 **语言下拉框** 实时切换语言：

1. 打开设置页面
2. 找到「语言」选项
3. 从下拉框中选择目标语言
4. 游戏立即应用翻译，无需重启

### 翻译文件加载

游戏启动时按以下顺序加载翻译：

1. 读取 `ProjectConfig` 中的 `language` 字段（项目默认语言）
2. 若为空，检测系统语言（`LANG`/`LC_ALL` 等环境变量）
3. 从 `assets/scripts/languages/<语言代码>.json` 加载翻译文件
4. 若文件不存在，使用原文模式（所有文本显示原文）

### 项目配置

在编辑器「项目设置」对话框的「运行设置」区域可配置：

| 字段 | 说明 |
|------|------|
| 默认语言 | 项目启动时使用的语言代码（如 `ja-JP`），留空则检测系统语言 |
| 窗口标题 | 游戏窗口标题，留空则使用主标题 |
| 版本号 | 项目版本号（如 `v1.0.0`） |
| 默认分辨率 | 启动分辨率（默认 1920×1080） |
| 启动时全屏 | 是否以全屏模式启动 |

## 翻译文件目录结构

```
assets/
└── scripts/
    ├── demo.akrs                  原文剧本（不修改）
    └── languages/
        ├── zh-CN.json             简体中文翻译
        ├── zh-TW.json             繁体中文翻译
        ├── en-US.json             英语翻译
        └── ja-JP.json             日语翻译
```

> 每个翻译文件与原文剧本一一对应，新增语言只需在 `languages/` 目录下添加对应 JSON 文件。

---

## 注意事项

1. **原文不可修改** — 翻译文件以原文为 key，修改原文会导致翻译失效。如需修改原文，请重新运行 `translate init` 生成骨架并重新翻译。
2. **角色名仅替换显示** — 逻辑层（角色上场/下场/存档/跳转）始终使用原文角色名，翻译仅在屏幕显示时生效。
3. **空译文回退原文** — 译文为空字符串时自动回退显示原文，不会报错。
4. **热重载兼容** — 修改翻译文件后可通过热重载即时生效，无需重启游戏。
5. **存档兼容** — 存档中保存的是原文文本和章节名，切换语言不影响存档加载。
